# Basemodo for agents

The Basemodo Plugin: skills that teach your agent to deploy, share and fix Apps on [Basemodo](https://basemodo.com), and Basemodo's Remote MCP, so the agent acts for you once you sign in. It works in claude.ai, ChatGPT, Claude Code, Codex, Cursor, VS Code, Gemini and the other agents that take plugins.

To set Basemodo up for your agent, start at [Deploying with an agent](https://basemodo.com/docs/agents).

Everything here is written by the `basemodo` CLI on each of its releases: a change made here by hand is replaced by the next release.
