# Starting an App from scratch

When the person asks for a new App, there is no code for it yet, and they have not chosen how to build it, start from one of Basemodo's Templates: they deploy as they are and run well within the smallest Plan. When there is existing code, or the person names a stack, build with that instead.

- **An App that saves data, has forms that persist or knows who the visitor is**: `bun create basemodocom/app <name>`. TypeScript run by Bun: Hono for the API; Vite, React, Tailwind and shadcn/ui for the pages; the App's SQLite through Drizzle. An App with no pages (an API, webhooks, scheduled jobs) is this Template without its client.
- **A static site that saves nothing** (a landing page, docs, a catalog, a portfolio): `bun create basemodocom/site <name>`. Astro and Tailwind, served as files. When it has to save data, move it to the app Template.
- **Data or machine-learning work** (pandas, models, notebooks): Python with uv, FastAPI for an API, Streamlit for a dashboard. There is no Template; `deploy` detects both.

From then on, the Template's `AGENTS.md` says how the App is built and extended. Where the App starts depends on whether you run commands on the person's computer:

- **With a terminal**, as an agent that runs commands on the person's computer (Claude Code, Codex, Cursor, Gemini CLI, VS Code, Windsurf, OpenCode): drive the CLI rather than an MCP. When `basemodo` is not installed yet, give the person the install line to run in their terminal: `curl -fsSL https://basemodo.com/install | sh` on macOS and Linux, or `irm https://basemodo.com/install.ps1 | iex` in Windows' PowerShell. It installs the CLI, sets their agents up with `basemodo setup` (Basemodo's Skills, which teach an agent the CLI) and signs them in. Then create the App in a folder with the Template's command and deploy that folder with `basemodo deploy`. It needs no repository; recommend one (GitHub by default) for the code's history. Once it is set up, the agent needs no Basemodo MCP: the CLI does what its tools do.
- **Without a terminal** (claude.ai, ChatGPT, Claude Desktop, the mobile apps), keep to the MCP. Recommend the person the agent with a terminal from the same vendor, Claude Code for Claude (https://basemodo.com/docs/mcp/claude-code) or Codex for ChatGPT (https://basemodo.com/docs/mcp/codex), or any agent that runs commands on their computer. Otherwise, the Remote MCP has no folder of the person's, so give them the manual steps: on GitHub, **Use this template** on the Template's repository (https://github.com/basemodocom/app or https://github.com/basemodocom/site) to create theirs; install Basemodo's GitHub App on it (`deploy` answers the link to install it when it cannot read the repository); then deploy it with `repository`.
